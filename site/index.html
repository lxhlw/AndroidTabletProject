About

Simple, lightweight, built for legacy devices

A floating volume controller for Android 4.4.2 tablets. Keep a compact button on screen, expand it for volume controls, drag it anywhere, and start automatically after boot.

安装说明 Installation Guide
首次安装 下载最新的 L101VolumeFloat.apk，直接在 Android 4.4.2 平板上安装。
旧版升级 如果已经安装过同一 Release 签名的旧版本，直接安装新版本即可，无需卸载。
如果提示签名不一致 说明设备上的旧版本使用了不同签名。先卸载旧版本，再安装新的正式 Release APK。
ADB 安装 将 APK 放在电脑当前目录后执行：
adb install -r L101VolumeFloat.apk
First installation Download L101VolumeFloat.apk and install it normally on the Android 4.4.2 tablet.
Upgrading Official Release APKs use the same signing key, so later versions can be installed directly over the existing app.
If Android reports a signature mismatch The installed copy was signed with a different certificate. Uninstall the old copy first, then install the new official Release APK.
ADB installation Put the APK in the current computer directory and run:
adb install -r L101VolumeFloat.apk
